# Contributing

Thanks for helping improve **Stolperbeats Pattern Generator**!

## Setup
- Node.js v20 (or v18 LTS)
- `npm install`

## Commands
- `npm run dev` – Next.js dev server
- `npm run dev:electron` – Electron + Next dev
- `npm run build` – Next build (Vercel)
- `npm run build:renderer` – Next static export (Electron packaging)
- `npm run dist` – Build Electron app (.app/.dmg)
- `npm run typecheck` – TypeScript type check
- `npm run lint` – ESLint

## Pull Requests
- Create a feature branch.
- Run `npm run typecheck && npm run lint && npm run build` before opening PR.
- Describe what & why. Add screenshots if UX changes.
